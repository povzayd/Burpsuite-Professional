# 🛠️ Installation Guide (Zero-Error Method)

This guide ensures a clean installation of **BurpSuite Professional** on Kali Linux, specifically addressing and fixing the common **"Invalid Key"** or **"Key Not Valid"** errors.

---

### 1. Prerequisites: Java Environment
BurpSuite Pro requires a specific Java Runtime environment to handle the activation loader properly. 

* **Download:** [Oracle JDK 21 Archive](https://www.oracle.com/java/technologies/javase/jdk21-archive-downloads.html)
* **Note:** Ensure you select the `.deb` package for Kali or the `x64 Debian` version.

### 2. Automated One-Line Setup
Run the following command in your terminal to clone the repository, set permissions, and execute the optimized installer script:

```bash
git clone https://github.com/povzayd/Burpsuite-Professional && cd Burpsuite-Professional && chmod +x install.sh && ./install.sh
```
